# Test images

Synthetic placeholder scenes (coloured background + label), generated with sharp. They are not
photographs and contain no people. MOCK_TESTING §5.1 describes the fuller set (EXIF variants,
edge cases) that Phase 3 adds.

| File | Use |
|---|---|
| `dumped-tyres.jpg` | JPEG, dumping scenarios |
| `turtle-nest.png` | PNG, turtle scenarios |
| `reef-damage.webp` | WebP, reef scenarios |
