## Decisions
1. **RustFS instead of MinIO.** MinIO's Docker images are no longer published (Docker Hub repository gone, quay.io unreachable). RustFS is S3-compatible, Apache-2.0, and passed an Object Lock compliance test (deleting a locked version → AccessDenied). Production still targets any S3 with Object Lock. Server-side encryption (SSE-KMS) is deferred to Phase 3 where the vault client is written.
2. **Web and worker run on the host**, not in compose, for fast reloads. Production Dockerfiles come in Phase 8.
3. **Routing rule ids** are `R<priority>` in config and tests; priorities must be unique (loader enforces). In the DB, rules get UUIDs.
4. **Placeholder geography** was drawn so every fixture place falls in its `area_hint` area and on the right side of the coastline; district boxes are clipped to the land polygon by the seed. Spaans Lagoen is modelled as a Ramsar area with no managing agency, so it routes to DNM (the real arrangement is a §16 item).
5. **Mock-mode intake addresses**: seeding with `MOCK_MODE=1` replaces agency emails with `dnm-intake@rocan.test` etc. so each agency has its own Mailpit inbox.
6. `/readyz` on the public web app returns only check names and ok/fail; the worker (internal) includes error text.
7. The state machine also enforces **which actor type** may trigger each event (e.g. only staff approve, only the reporter submits or withdraws).
8. Auto-dispatch also treats `location_mismatch`, `classifier_failed`, `classifier_skipped` and `outside_aruba` as blocking, in line with the conservative default.

- The preinstalled Chromium in some sandboxes is older than Playwright 1.63 expects; use `PLAYWRIGHT_CHROMIUM_PATH`. CI installs the matching build.
- `apps/web/AGENTS.md` is generated by `next dev` and committed so it doesn't show up as a change; Turborepo's equivalent is disabled with `agentGuidance: false`.
